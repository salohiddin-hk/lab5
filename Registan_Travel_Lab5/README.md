# Registan Travel — CSIT248 Lab Work 5

## Included
- `index.html`: responsive hand-written CSS Home page
- `booking.html`: booking form with live total, discount, and validation
- `index-bootstrap.html`: Bootstrap 5 Home page
- `css/style.css`: shared CSS
- `js/main.js`: browser-side price calculation and validation

## Run in VS Code
1. Extract the ZIP and open the `Registan_Travel_Lab5` folder in VS Code.
2. Install the Live Server extension if needed.
3. Right-click `index.html` and select **Open with Live Server**.
4. Test `booking.html` through the navigation menu.
5. Open `index-bootstrap.html` to test the Bootstrap version (internet is needed for the Bootstrap CDN).

PHP and a database are not required. Booking is only checked in the browser, as specified in the case study.
